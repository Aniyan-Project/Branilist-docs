# Branilist API Docs

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

VitePress, confirmado pelo usuário. Publicação estática no GitHub Pages.

## Users

Desenvolvedores que integram a API pública REST do Branilist e precisam localizar rotas, parâmetros, autenticação, respostas e exemplos.

## Product Purpose

Transformar a documentação Markdown existente em um site navegável, com busca e referência gerada automaticamente pelo OpenAPI.

## Operating Context

O repositório público Aniyan-Project/Branilist-docs contém os guias e openapi.json. O usuário confirmou que essas são as fontes da atualização automática. Mudanças no código privado da API não são inferidas por este site.

## Capabilities and Constraints

Navegação lateral, índice por página, busca local, temas claro/escuro, exemplos de código e publicação por GitHub Actions após mudanças na branch principal. Novas operações e schemas no OpenAPI entram automaticamente na referência. Novas páginas em docs entram automaticamente na navegação.

## Brand Commitments

Nome Branilist. Idioma português. O usuário escolheu o site docs.anilist.co/guide/introduction como referência de leitura e organização; manter uma interface de documentação, sem criar uma landing page promocional.

## Evidence on Hand

Guias em docs, especificação openapi.json, exemplos executáveis em examples. Os exemplos com IDs e dados são ilustrativos.
